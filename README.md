# 🍔 Foody - Food Delivery Database Management System

A database-driven web application designed to simulate an online food delivery platform. The project demonstrates efficient database design, SQL operations, and a user-friendly interface for managing restaurants, customers, orders, and deliveries.

## 📖 About

Foody is a food delivery management system that models the workflow of an online food ordering platform. It provides a structured database to manage restaurants, menu items, customers, orders, payments, and delivery details while offering a simple frontend interface for interacting with the system.

This project was developed to demonstrate database design concepts, SQL queries, relational database management, and frontend integration.

## 💻 Run Locally

Clone the repository

```bash
git clone https://github.com/codewithkanishka01/Food-Delivery-Database-Project.git
```

Navigate to the project

```bash
cd Food-Delivery-Database-Project
```

Open the project using **Live Server** or any static web server.

If you're using MySQL, import the SQL database file into your local MySQL server before running the application.
